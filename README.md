# HOTS NGS analysis

Draft and match analysis for Phoenix Rising Amethyst (Nexus Gaming Series, Division C West). Everything needed to continue the work is in this repo.

- New session (Claude Code): open it in this folder and say "HOTS project". It reads `CLAUDE.md`, then `PROJECT_STATE.md`.
- Draft tool for match night: `draft_tool.html` (any browser), or the private phone link in `CLAUDE.md`.
- Updating after a match: `UPDATE_PLAYBOOK.md`.
